📬 mail_telegram – Telegram Integration for Odoo

mail_telegram is an Odoo module that enables Telegram messaging directly inside your Odoo environment. Send quotations, invoices, payslips, and other business documents to customers via Telegram using customizable templates.

Users can also receive Telegram notifications when they are mentioned in chatter messages or internal log notes.

🚀 Key Features

✅ Send Reports via Telegram

Send invoices, sale orders, payslips, and other reports directly to customers through Telegram.

✅ Custom Telegram Templates

Create reusable Telegram templates similar to Odoo email templates.

✅ PDF Report Attachments

Automatically attach generated QWeb PDF reports when sending messages.

✅ Mention Notifications

Receive Telegram alerts when users mention you in chatter messages or notes.

✅ Telegram Composer Wizard

Open a composer wizard similar to Odoo’s email composer with template preview and instant sending.

✅ MarkdownV2 Support

Messages are formatted using Telegram MarkdownV2 for rich and professional output.

📦 Installation

git clone https://github.com/aosqa/mail_telegram.git


./odoo-bin -u mail_telegram
  1. Copy the module into your Odoo addons directory.
  2. Restart the Odoo server.
  3. Install the module from Apps.
  4. Go to: Settings → Technical → Telegram and configure your Telegram bot.

🛠️ Configuration

  1. Create a Telegram bot using @BotFather
  2. Store your bot token in system parameters:
telegram.bot_token
  1. Fill the following partner fields:
    • telegram_username
    • telegram_chatid
  2. You can use bots like @RawDataBot to get the chat ID.

🧠 How It Works

1️⃣ Define a Telegram Template

Create Telegram templates similarly to Odoo email templates and attach reports if needed. 

<record id="telegram_template_sale_order" model="telegram.template">
    <field name="name">Send Sale Order via Telegram</field>
    <field name="model_id" ref="sale.model_sale_order"/>
    <field name="body_html">
        Hello,
        Your quotation {{object.name}} is ready.
    </field>
</record>

2️⃣ Open Telegram Composer

Trigger the Telegram composer wizard directly from your document. 

def action_send_telegram(self):
    ctx = {
        'default_model': 'sale.order',
        'default_res_id': self.id,
    }

📨 Chatter Notifications

When users are mentioned in chatter messages or internal notes, they automatically receive Telegram notifications if their Telegram information is configured.
